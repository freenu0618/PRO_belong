확장 로드맵(UI 관점)

지금은 구현된 기능(대시보드/AI챗봇)을 안정화하고, 확장 기능을 “붙일 수 있는 구조”를 유지합니다.

Phase 1
UI 구조 안정화
공통 컴포넌트(네비/레이아웃) 단일화, 전역/페이지 CSS 분리, 엔드포인트/ID/클래스 규칙 고정.
Phase 2
AI Agent UI 스켈레톤
“준비중” 탭에 실제 페이지 연결, 상태/로그/결과를 보여주는 레이아웃부터 확장.
Phase 3
Agentic AI 확장
워크플로우/멀티 에이전트 시각화(실행흐름, 도구 호출, 결과물)를 대시보드와 연결.
