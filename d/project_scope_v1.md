# 1. 프로젝트 범위(Project Scope) & 결과물 정의

## 1-1. 프로젝트 한 줄 요약
**서울 25개 구의 독거노인 인구를 분석·시각화하고, 연도별 변화를 기반으로 향후 인구를 예측하는 데이터 분석/웹 서비스.**

---

## 1-2. 핵심 목표(3가지)

### 1) 독거노인 인구 분석  
- 서울 25개 구 × 연도별 독거노인 인구 추이를 한눈에 확인  
- 증가/감소 추세 비교 및 변화량 분석 가능  

### 2) 상관관계 분석  
독거노인 인구와 다음 변수들의 상관도 분석:  
- 고령화지수  
- 저소득 노인 수  
- 복지시설 수  
- 65세 이상 인구  
- 1인 가구 수  

### 3) 독거노인 인구 예측  
- 각 구별 향후 1~2년 인구 예측  
- LinearRegression 기반 단순 예측 모델(v1)  
- 예측값을 그래프로 제공  

---

## 1-3. 데이터 범위  
- **공간 범위**: 서울시 25개 구  
- **시간 범위**: 2015 ~ 2023년(데이터 확보 범위 기준)  
- **단위**: 연도(year), 구(region)  

---

## 1-4. 사용자 기능(결과물)

### 1) 대시보드
- 각 구의 최신 독거노인 인구  
- 최근 5년 증가율  
- 추세 그래프 미리보기  
- TOP 상승/하락 구 표시  

### 2) 구 상세 페이지  
- 연도별 상세 그래프  
- 향후 1~2년 예측 그래프  
- 요약 인사이트 카드  

### 3) 상관관계 분석 페이지  
- 히트맵(style 선택 가능)  
- 각 변수별 상관계수 표시  

---

## 1-5. 기술 범위

### 백엔드/ML  
- Python 3.x  
- Flask (Blueprint 구조)  
- Pandas, NumPy  
- scikit-learn (LinearRegression 기반 v1)  
- joblib  

### 프론트  
- Flask 템플릿 기반
